# Multi-Domain Intelligence Platform

A Streamlit-based web application that provides dashboards for Cybersecurity, IT Operations, and Data Science.  
This project demonstrates both a procedural implementation (Week 9) and an object-oriented refactored version (Week 11).

---

## Project Overview

The Multi-Domain Intelligence Platform allows users to log in and access multiple intelligence domains from a single interface.  
Users can manage data, view analytics, and receive AI-assisted insights.

The application is built using Python, Streamlit, and SQLite and focuses on clean design and good programming practices.

---

## Key Features

- User login and registration
- Session-based authentication
- Three intelligence domains:
  - Cybersecurity
  - IT Operations
  - Data Science
- Full CRUD functionality (Create, Read, Update, Delete)
- Interactive tables and charts
- AI-powered insights and recommendations
- CSV data viewing and basic statistics
- Simple and responsive Streamlit UI

---

## Domains

### Cybersecurity
- Report and manage cyber incidents
- Track severity and status
- View incident analytics
- AI-assisted incident analysis

### IT Operations
- Create and manage IT support tickets
- Categorise tickets (hardware, software, network, etc.)
- Track ticket status and resolution
- AI-generated resolution suggestions

### Data Science
- Register datasets and metadata
- Track file size and record count
- Organise datasets by category
- AI-recommended analysis approaches
